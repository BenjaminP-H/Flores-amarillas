# 🌻 Flores Amarillas — Detalle Especial

Una página web romántica e interactiva diseñada con animaciones en CSS, música de fondo y letras sincronizadas para regalar en el día de las flores amarillas / primavera.

🔗 **Demo en vivo:** [https://benjaminp-h.github.io/Flores-amarillas/](https://benjaminp-h.github.io/Flores-amarillas/)

---

## ✨ Características

- 🌻 **Flores Amarillas Animadas:** Animaciones CSS puras con efectos de iluminación, tallos en movimiento y cielo nocturno estrellado.
- 🎵 **Música de Fondo:** Canción *"Flores Amarillas"* de Floricienta.
- 📝 **Subtítulos Sincronizados:** Letras dinámicas que aparecen y desaparecen en tiempo real coordinadas con la música.
- 📱 **Totalmente Responsivo:** Optimizado con aceleración por hardware (GPU) para reproducirse de forma fluida en computadoras y celulares (iOS y Android).
- 💡 **Portada Interactiva:** Texto con animación estilo LED dorado y botón interactivo con efectos de luz.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica y reproducción de audio web.
- **CSS3:** Animaciones clave (`@keyframes`), flexbox, variables CSS, gradientes y diseño responsivo.
- **JavaScript (Vanilla):** Lógica de sincronización temporal con eventos de audio (`timeupdate`) y compatibilidad móvil.
